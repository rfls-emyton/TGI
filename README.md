# TGI: Topological Geometric Intelligence

Research implementation by Emylton Leunufna. This repository contains the Python runtime, a minimal reproducible acceptance example and regression tests, and six manuscripts with PDF renderings. NMU retains one static ID per Unicode scalar; the mechanisms are derived from the TGI program.

Python >=3.11. Local check: `python -m unittest discover -s tests -q`. CLI: `python -m tgi --help`. See `paper/technical/README.md` for the foundational and five technical papers. Raw research evidence and historical hypotheses are intentionally outside this public code tree.
