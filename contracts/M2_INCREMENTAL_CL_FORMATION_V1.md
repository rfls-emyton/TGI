# Incremental formation of source-owned C/L port classes

This is a post-implementation validation contract for an execution change to
the existing TGI C/L formation operator. It does not change the class,
crystallization, `Omega`, `xi`, comparator, or revocation decision.

For each original ordered event, class membership remains the equivalence
partition of complete per-port response signatures. For a live class and its
current epoch, add the new source's exact before-NMU context to the action's
C-band support set when every member changed. Increment that action's L-band
control count when every member stayed stable. Record the action as a
comparator witness when the class is stable while another port changes.
`Omega` is the cardinality of the support set, and the comparator for an
action exists only when a different action is recorded. If a class appears
after a split, replay its sources from the current epoch. If the prior class
fractures, start a new epoch and discard the prior accumulator.

The recurrence must produce the exact same phase certificate as the frozen
exhaustive source implementation on randomized raw Unicode streams, explicit
fracture/recrystallization panels, and held-out endpoint decisions. The
independent runtime verifier must accept that certificate and reject altered
phases. Production timing compares identical raw sources and identical
certificate hashes against the published predecessor, including at least
1,005 new-epoch sources. A runtime reduction is an implementation property;
it is not new semantic evidence or an assertion of universal scale.
